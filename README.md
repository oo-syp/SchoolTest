# SchoolTest 1.0

Тестирование учащихся, студентов и работников в локальной сети: один exe-файл на компьютере учителя, участники проходят тест в браузере на любых устройствах той же сети. Интернет не нужен.

**Общественная организация «Союз юных педагогов»**
Разработчик: Костянко Денис Александрович
Витебск, 2026

## 1. Быстрый старт

1. Скопируйте `SchoolTest.exe` в отдельную папку на компьютере учителя (Windows 7–11) и запустите. Рядом появится папка `SchoolTest_data` — в ней база `schooltest.db` и резервные копии.
2. Один раз запустите `firewall_open_port.bat` от имени администратора — он откроет порт 8081 в брандмауэре Windows.
3. В окне программы показаны адреса. Учитель входит по адресу с `/teacher` в конце (например, `http://192.168.1.10:8081/teacher`), логин `admin`, пароль `admin` — программа сразу попросит сменить пароль.
4. Выберите тип организации, добавьте списки и учителей, создайте тест, нажмите «Провести».
5. Ученики открывают адрес без `/teacher` (`http://192.168.1.10:8081`), вводят 6-значный код и выбирают себя в списке.

Порт 8081 выбран, чтобы SchoolTest и SchoolGrade (порт 8080) могли работать на одном компьютере. Другой порт: `SchoolTest.exe --port 8090`.

Забыт пароль администратора — кнопка «Сбросить пароль администратора» в окне программы на компьютере учителя покажет временный пароль.

## 2. Возможности

**Тип организации** — школа (учитель, ученик, класс; связь с SchoolGrade), ВУЗ/колледж (преподаватель, студент, группа), предприятие (ответственное лицо, работник, подразделение; итог теста: отметка 1–10, «сдал / не сдал», процент или «зачёт / незачёт»).

**Списки** — вручную, вставкой списка ФИО, из таблицы XLSX/XLS/CSV с предпросмотром, из файла выгрузки SchoolGrade или напрямую из SchoolGrade по сети. Повторная загрузка обновляет списки без дублей.

**Типы вопросов** — один верный ответ; несколько верных (частичный балл по нормам, пропорционально или только полный ответ); короткий ответ (несколько полей, список допустимых ответов, без учёта регистра, числа с погрешностью); соответствие; порядок; хронологическая рулетка (события перетаскиваются на ленту времени «раньше — позже», на телефоне лента вертикальная); пропуски в тексте (вписать или выбрать); шкала Ликерта (опрос, не оценивается); развёрнутый ответ и практическое задание с файлом (проверяет учитель). В вопросы и варианты добавляются картинки, звук с ограничением числа прослушиваний и **математические формулы**: кнопка «ƒx» открывает редактор с палитрой (дроби, корни, степени, индексы, греческие буквы, функции, системы, матрицы, векторы и т. д.), записью LaTeX и мгновенным предпросмотром. Формулы отображаются библиотекой KaTeX, встроенной в программу (без интернета).

**Структура теста** — задания, варианты, банк вопросов (из задания каждому выдаётся заданное число случайных вопросов), баллы за вопрос.

**Оценивание** — у каждого теста своя шкала: по проценту выполнения (по умолчанию 95 % → 10, 85 % → 9, 75 % → 8, 65 % → 7, 55 % → 6, 45 % → 5, 35 % → 4, 25 % → 3, 15 % → 2, ниже → 1; администратор меняет шкалу по умолчанию, учитель — для своего теста) или по нормам оценки результатов учебной деятельности (методические указания 2022 г.): тестовая работа по белорусскому и русскому языку, комплексная работа с текстом, работы из 5 заданий уровней I–V, комбинированная работа, работа из 10 заданий.

**Импорт и экспорт** — файл теста SchoolTest (`.stest`, со всеми картинками и настройками — для обмена между школами); текст из Word или файл `.txt` по разметке (`+`/`-` — варианты, `=` и `= {подпись:}` — короткий ответ, `1.` `2.` — порядок, `?` — вопрос в стиле «Ассистент II», `[файл.jpg]` — картинка; картинки загружаются вместе с текстом или ZIP-архивом); таблица Excel по шаблону (все типы вопросов). Перед сохранением показываются распознанные вопросы и строки, которые не удалось разобрать. Импорт из MyTestX, «Ассистент II» (файлов) и Moodle — в следующей версии.

**Проведение** — код теста, выбор себя в списке, наблюдение в реальном времени (кто вошёл, прогресс, время, уходы со страницы, на связи ли), добавление времени, завершение попытки, повторное прохождение по разрешению. Защита от списывания: перемешивание вопросов и вариантов, варианты и банк, ограничение времени, фиксация ухода со страницы с журналом, запрет копирования, строгий порядок вопросов. Один ученик не войдёт дважды без разрешения учителя. Ответы сохраняются на сервере после каждого действия; при сбое ученик продолжает с того же вопроса на любом устройстве после разрешения учителя (таймер идёт).

**Бумажный тест** — печать вариантов с перемешиванием и ключа ответов; вопросы со звуком и файлами исключаются с предупреждением; отметки вносятся вручную или отправляются в SchoolGrade.

**Результаты** — что видит ученик (ничего / итог / итог и разбор с правильными ответами); проверка развёрнутых ответов и файлов с комментариями; отчёты «Результаты класса», «Анализ вопросов» (доля верных, средний балл, самые частые ошибки, ответы опросов), «История ученика» — в Excel и на печать.

**SchoolGrade** (версия 1.3 и новее) — по сети: в SchoolGrade «Администрирование → Связь с SchoolTest» включите связь и скопируйте ключ; в SchoolTest «Настройки → Связь с SchoolGrade» укажите адрес и ключ. Списки обновляются кнопкой «Обновить из SchoolGrade», отметки отправляются со страницы запуска (урок с видом работы «тест» на дату теста, повторная отправка не дублирует урок). Без сети — файлами: списки классов (`.sgclasses.json`) и отметки (`.sgmarks.json`, в журнале SchoolGrade кнопка «Отметки SchoolTest»).

**Язык** — русский и белорусский; язык по умолчанию задаёт администратор, учитель и ученик переключают его на своём экране.

**Данные и безопасность** — всё в одном файле `schooltest.db`; резервная копия раз в сутки и по кнопке, восстановление; пароли — только хеш (PBKDF2); правильные ответы не передаются на устройство ученика до завершения теста (а в строгом режиме — даже другие вопросы); загружаемые файлы проверяются по типу и размеру, исполняемые запрещены; файлы отдаются браузеру в «песочнице»; подбор кода ограничен; данные не покидают компьютер учителя.

## 3. Отличия от ТЗ (согласовать)

* Восстановление из резервной копии доступно только администратору (создать копию может и учитель) — восстановление заменяет все данные школы.
* Порт по умолчанию 8081 (в ТЗ пример 8080 — его занимает SchoolGrade).
* Кроме 64-битной собрана 32-битная версия для старых компьютеров с Windows 7 x86.
* Служебной учётной записи разработчика нет: забытый пароль администратора сбрасывается кнопкой в окне программы (нужен доступ к компьютеру учителя).

## 4. Проверка

* `python -m unittest discover tests` — API, проверка ответов и шкал, нормы, импорт текста и Excel, файл теста, бумажный тест, строгий режим и таймер, связь с SchoolGrade (если рядом лежат исходники SchoolGrade 1.3).
* `python tests/load_test.py` — 60 учеников одновременно проходят тест из 20 вопросов при работающем наблюдении учителя: все ответы сохраняются, задержка — единицы миллисекунд.

## 5. Разработка и сборка

Только стандартная библиотека Python 3.8 (последняя версия для Windows 7). Запуск из исходников: `python run_server.py` (`--nogui`, `--port`, `--data`, `--local`). Сборка exe: `build.bat` (Python 3.8.10, PyInstaller 5.13.2, `SchoolTest.spec`). 32-битный Python даёт exe для любой Windows, 64-битный — только для x64.

```
schooltest/
  main.py         окно сервера (tkinter), запуск, автокопии
  server.py       HTTP-сервер, маршрутизация, защита
  db.py           схема SQLite, резервные копии
  auth.py         пароли, сессии, коды тестов
  grading.py      проверка ответов, нормы оценки, шкалы
  engine.py       снимок теста, план попытки, вид вопроса для ученика
  attempts.py     завершение, пересчёт, контроль времени
  api_*.py        API: администрирование, списки, тесты, проведение, ученик, импорт
  sgbridge.py     связь с SchoolGrade
  i18n.py         белорусский язык (словарь static/be.tsv)
  static/         интерфейс учителя (index.html, app_*.js), ученика (student.*), KaTeX
tests/            автотесты и нагрузочный тест
```
